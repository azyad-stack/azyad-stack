## 🚀 Featured Project

### 📦 Container Detection & Tracking System

A full-stack system designed for container tracking and automatic container identification.

**What it does:**

* 🎯 Detects containers using YOLO
* 🔎 Extracts container identification codes using OCR
* ✅ Validates container numbers using ISO 6346 checksum
* 🗄️ Stores container information in PostgreSQL
* ⚡ Provides a FastAPI backend
* 💻 Provides a React + TypeScript frontend
* 🐳 Designed for containerized deployment

**Tech Stack**

`Python` `YOLO` `OpenCV` `EasyOCR` `FastAPI` `SQLAlchemy` `PostgreSQL` `React` `TypeScript` `Docker`
